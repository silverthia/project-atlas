# Atlas AI Development Guide

## Filosofia

- Documentação antes de código
- Simplicidade acima de sofisticação
- MVPs pequenos e testáveis
- Não fazer overengineering
- Não criar funcionalidades não solicitadas

## Workflow

Ideia
↓

Arquitetura
↓

Implementação
↓

Code Review
↓

Commit
↓

Push

## Regras

- Nunca fazer commit automaticamente.
- Nunca alterar múltiplos documentos sem necessidade.
- Sempre justificar decisões.
- Sempre fornecer git diff.
- Sempre sugerir um commit.
